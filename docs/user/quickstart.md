# Lignting Agents Quickstart（0.0.1 草稿）

> 状态：草稿（Q1，2026-11-17）。按 [requirements.md](../../doc/0.0.1%20最初版/requirements.md) v0.0.1 目标行为编写，R1–R9 实现后逐项校对。
> 当前进度：R0 只有最小启动与 /api/health；向导、助理、部门等页面在 R1–R4 逐步出现。文档先按目标体验写，避免实现完成后再补。

## 1. 你将得到什么

一个**只在本机运行**的 AI 团队工作台：

- 你以「项目主管」身份登录；
- 系统给你一个**助理 Agent**，先澄清目标，再提出产品/研发/测试**部门蓝图**；
- 你批准一次（G1），团队开始接任务；
- 一个真实需求从 PRD、部门内讨论、实现、评审、G3 验收走完；
- 所有消息、任务、产出、评审、决策、记忆写入本地，可搜索、可导出、可暂停。

v0.0.1 只用 DeepSeek 官方 API（默认 deepseek-flash），不做多供应商、多用户、多项目。

## 2. 准备

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10+ / macOS 12+ / 主流 Linux |
| 浏览器 | Chrome / Edge / Safari / Firefox 近两个大版本 |
| 模型 | DeepSeek API Key；没有 Key 也能启动，但 Agent 不能生成回复 |
| 磁盘 | 数据目录必须在**本机盘**，不要放 OneDrive/NAS/网络盘（SQLite WAL 要求） |
| 源码运行 | Go 1.26+（本机已验证 1.27）；后续提供单二进制 |

## 3. 启动

在仓库根目录：

~~~powershell
# 开发模式（默认 127.0.0.1:8787，数据在 .lignting-dev）
.\scripts\dev.ps1

# 用 mock 模型（无需 Key，界面标注「测试模式」）
.\scripts\dev.ps1 -Mock

# 换端口/数据目录
.\scripts\dev.ps1 -Port 8788 -DataDir .lignting-dev2
~~~

等终端打印地址后，浏览器打开 <http://127.0.0.1:8787>。默认只绑 loopback，局域网/公网访问需要显式配置（v0.0.1 不提供公网 TLS 方案）。

## 4. 首次向导（T1，目标 ≤10 分钟）

向导只问四件事，其余可稍后改：

1. **数据目录**：默认在用户目录下；可以改到 D 盘等本地盘。
2. **DeepSeek API Key**：输入后不明文回显；Key 存本机密钥文件（0600）或 OS keychain，不进消息/日志/检索。
3. **预算**：先填日/月上限（默认试用 20 元/天、300 元/月）；可随时追加。
4. **称呼**：助理怎么称呼你。

完成后，助理在私聊里主动出现，说明：能做什么、不做什么、如何暂停、如何查看它的行为。

## 5. 第一个闭环（T2 ≤30 分钟，T3 ≤1 个工作日）

1. **说目标**：例如「把现在的 CLI 工具做成一个带 Web 界面的产品，先做最小可用版」。
2. **确认意图卡**：助理问目标/用户/范围/约束/质量/预算/期限/风险/现有资产，生成一页意图卡；可编辑、版本化。未确认前不会创建部门。
3. **批准蓝图（G1）**：助理给「精简版/完整版」两档，含部门、角色卡、分工视角、群聊、预算、前三风险、成本估算。你可以改人数/预算；批准一次即蓝图+章程生效。
4. **系统组建部门**：创建产品/研发/测试部门、主管与员工、部门群聊、任务板、记忆空间；主管 kickoff 只复述目标/风险/第一里程碑，不再让你二次审批。
5. **第一个任务**：主管拆任务、写验收标准、派人；任务板可见每个员工的分工视角。
6. **部门内讨论**：如果接口/字段有分歧，在部门群聊里按视角讨论，每人≤5 条、总≤15 条，主管裁决并记录。
7. **G2（仅高风险）**：安全/数据/对外接口/发布类方案需要你批准；低风险由主管决定并留记录。
8. **实现与评审**：研发提交产出物版本；测试独立挑战；作者≠评审者；返工产生新版本，旧版本仍可查。
9. **核对与 G3**：部门主管逐条填验收核对表（证据→结论）；缺证据时 G3 不可提交。你批准后任务完成，产出归档，记忆候选提交，文件写入进入时间线。

## 6. 日常使用

- **收件箱**：只有「需要决定/阻塞」实时打扰；FYI/需要知道进收件箱，可批量/稍后/授权（有范围与到期）。
- **搜索**：顶部搜索支持中文 2 字、短语、中英混排、代码标识符；按部门/作者/时间/类型过滤；删除的消息搜不到。
- **记忆检查器**：按实体浏览，查看来源/置信度/生效失效/版本；可编辑、删除（留墓碑）、钉住；待审候选可批准/拒绝/合并；管理手册可 diff/回滚。
- **暂停/紧急停止**：顶部可暂停单个 Agent、部门或全局停止；恢复后状态保留，不重复副作用。
- **备份/导出**：设置页可备份、导出、导入；备份用数据库在线备份/导出，不要直接复制运行中的数据库文件。

## 7. 数据在哪

默认数据目录结构：

~~~text
<data-dir>/
  lignting.db          SQLite（WAL）
  workspace/           用户工作区（读/写/bash 的根）
  artifacts/           产出物内容（按 hash 存储）
  backups/             备份 zip
  logs/                结构化日志
  config.json          非敏感配置
  secrets.json         模型 Key（0600，不导出）
~~~

## 8. 当前限制（v0.0.1）

- 单用户、单项目；不支持多端同步、移动端、桌面壳。
- 只接 DeepSeek；不接 DSH/ACP/Node/MCP/其他模型。
- 不做全库加密；磁盘安全依赖 OS 账户与磁盘权限。
- 不做无限自主运行；关键节点需要你审批。
- 不做 Agent 市场/插件市场/跨组织 A2A。
